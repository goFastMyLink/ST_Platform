# Кинематика платформы «3 активные RSS + 3 пассивные SS»

Общий код для механизма с 3 серво и 3 тягами постоянной длины. Вся геометрия задаётся в одном файле параметров. Работает в MATLAB и GNU Octave, `global` не используется.

## Запуск
- `test_yellow`: проверка на жёлтой платформе. ПЗК совпадает со старыми `PZK_fun`/`OZK_fun`, круговая проверка ПЗК→ОЗК даёт ошибку ~1e-12°.
- `test_3servo`: трёхсерво-платформа. **Параметры пока заглушки**, их надо заменить в `params_3servo.m`.

## Файлы
| Файл | Что делает |
|---|---|
| `params_yellow.m`, `params_3servo.m` | геометрия платформы (основание, звенья, кривошипы, шарниры платформы) |
| `fk.m` | ПЗК: углы серво → `VZ`, `EA`. Неизвестные — 6 координат позы, уравнения — 6 длин тяг |
| `ik_pose.m` | ОЗК для полной позы `VZ`+`EA`: углы находятся аналитически, возвращаются обе сборки кривошипа и невязки пассивных тяг |
| `ik_3dof.m` | ОЗК, когда заданы только Z и два наклона: X, Y и рыскание определяются пассивными тягами |
| `workspace.m` | рабочая зона без точек, где решатель не сошёлся; цвет точки — рыскание |
| `deadPoint.m` | угол, при котором кривошип проходит мёртвую точку |
| `servoToPCA.m` | угол → импульс (мкс) → отсчёт PCA9685 |
| `rotEA.m`, `EAfromRot.m`, `legPoints.m`, `crankGeom.m`, `poseToVZ.m`, `VZtoPose.m`, `neutralPose.m` | вспомогательные функции |

## Конвенции (как в исходном коде)
- `EA = [th psi phi]` в градусах, `Rot = Rz(phi)·Ry(th)·Rx(psi)`.
- `VZ` смещена от плоскости шарниров платформы на `z_off` вдоль оси z платформы.
- Нога i соединяет нижний шарнир `A_i` с верхним `B_i`. `p.active` задаёт, какие ноги с серво и в каком порядке идут углы.
